Payout Reconciliation

Payout audit for restaurants on Turkish delivery platforms

Computes what a delivery platform should have paid from the restaurant's own POS records and contract terms, compares it with the payout statement, and attributes every missing lira to exactly one cause.

  • Date-ranged commission rules (rate, base, fixed fee, processing fee, VAT, delivery) with a line-by-line breakdown for every order.
  • 12 discrepancy types; each underpaid amount gets a single cause, so the dispute total is never double-counted.
  • On the generated benchmark month: all 30 planted errors found, 0 false positives, a 3,599.95 TL shortfall (5.4%) fully explained. Not yet run on a real platform statement.
  • Python standard library and SQLite, runs locally; unit, regression and HTTP tests with GitHub Actions CI.

Turkish Emotion Classifier

7-class NLP system with a measured negative result
